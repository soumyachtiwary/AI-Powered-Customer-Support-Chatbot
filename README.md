# AI-Powered Customer Support Chatbot

A simple NLP-powered customer-support chatbot built with Python, NLTK, Flask, and SQLite.

## Features
- FAQ-style customer support responses
- NLP preprocessing using NLTK tokenization and stemming
- Similarity-based response selection
- Flask web interface
- SQLite conversation logging

## How to run

1. Create/activate a Python virtual environment (optional).
2. Install dependencies:

```bash
pip install -r requirements.txt
```

3. Run:

```bash
python app.py
```

4. Open the local URL shown in the terminal, usually:
`http://127.0.0.1:5000`

## Example questions
- How can I reset my password?
- How do I create an account?
- How can I contact customer support?
- How do I update my profile?
- How can I check my order status?
